# 图形编辑器

独立的 Qt / PySide6 桌面编辑器，复用原有蓝牙打印协议。当前支持 12 mm 覆膜 TZe、
单张横向自动长度 LBX 的图文编辑，不是完整 P-touch Editor。

## 启动

Fedora 需要原命令行依赖，另加 Qt Python 绑定：

~~~bash
sudo dnf install python3 python3-pillow liberation-sans-fonts bluez python3-pyside6
./launch-gui.sh
./launch-gui.sh '/path/to/label.lbx'
~~~

也可运行 python3 -I -B scripts/ptd610bt_gui.py。
启动及打开文件均不会查询设备或打印。--mac 与 --channel 可预填配对设备信息，仅用于当前会话。
程序不自动配对、安装服务或修改已有双击直接打印关联；PySide6 是可选 GUI 依赖。

## 编辑

1. 新建标签或打开支持的 LBX，在对象列表选择文字/图片。
2. 修改文字、字号、粗体及位置/尺寸，应用后检查预览。
3. 可增加文字或嵌入图片、调整内容长度，并使用撤销/重做。
4. “另存为”仅保存到全新文件；已存在的文件（包括原文件）一律拒绝覆盖。

文字块有混合样式时，应用文字修改会统一该文字块的字号和粗细。
Arial 使用 Fedora Liberation Sans 替代；未支持字体、带宽、旋转、多页、条码等布局会明确报错。
不保证中文等超出所用字体字形范围的文字正确显示，请先检查预览。
导出 LBX 可在本编辑器重新打开；尚未验证所有导出文件在官方 P-touch Editor 中的往返兼容性。

没有自动保存。切换或关闭时会提示处理未保存及尚未应用的更改；
取消另存为或保存失败不会丢弃当前编辑状态。

## 蓝牙打印

先用系统蓝牙设置完成配对，在界面输入设备地址（通道默认 2），查询状态后点击打印。
打印按钮直接发送一张当前预览，无需先保存。没有自动测试打印或自动重试。

通信在后台执行，任务期间禁止重复提交和修改标签，完成后再继续。
显示“结果不确定”时先检查实际出纸，再决定是否手动重试。
小留白模式可能先裁掉约 23 mm 空白前导带；内容长度与最终裁切长度不同。

## 验证

~~~bash
QT_QPA_PLATFORM=offscreen python3 -I -B -m unittest discover -s tests -v
~~~

自动化使用合成标签、模拟蓝牙及离屏窗口，不会打印或改变主机关联。
旧的 36 项协议、LBX、桌面配置测试继续保留。
